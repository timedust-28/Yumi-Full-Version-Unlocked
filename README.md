## Overview
<a id="overview"></a>

YUMI (Your Universal Multiboot Installer) is a versatile tool designed to help users create a bootable USB drive that can hold various applications and operating systems. Ideal for tech enthusiasts, IT professionals, and anyone who needs to carry essential software on the go, YUMI simplifies the process of installing multiple operating systems from a single USB stick. Compared to typical alternatives, YUMI offers a user-friendly interface and efficient setup process.

## Main Features
<a id="main-features"></a>

### Core Functionality
- **MultiBoot Support** — YUMI allows users to install multiple operating systems on a single USB drive, making it a practical choice for tech enthusiasts.
- **Auto-Exec Capability** — Automatically executes your preferred applications and operating systems upon boot, streamlining the user experience.
- **Syslinux and GRUB Compatibility** — Utilizes syslinux for launching distributions and can directly boot ISO files with GRUB, increasing versatility.
- **Uninstallation Support** — Easily remove unwanted distributions from your USB drive, keeping your options organized and clutter-free.
- **Storage Integration** — Besides booting applications, YUMI allows users to store files in the same multiboot folder, maximizing USB utility.

- **Offline Mode** — YUMI allows users to create a bootable USB without requiring an internet connection after the initial download.
